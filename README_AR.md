# تطبيق المساعد الصوتي المحلي دون إنترنت (Offline Voice Assistant)
تطبيق أندرويد مستقل يعمل بدون إنترنت لتحويل الصوت العربي إلى نص وتنفيذ الأوامر:
1. إجراء المكالمات الهاتفية المباشرة (Intent.ACTION_CALL) بعد مطابقة الأسماء من جهات الاتصال (ContactsContract).
2. فتح التطبيقات المثبتة محلياً (PackageManager).
3. البحث بالمتصفح أو المحلي كإجراء بديل.

اللغة المختارة: Kotlin

---

## 🚀 كيفية استخراج ملف APK مباشرة من موقع GitHub دون الحاجة لتثبيت Android Studio:

1. أنشئ مستودع جديد على حسابك في GitHub (New Repository) وسمّه مثلاً `offline-voice-assistant`.
2. ارفع جميع ملفات هذا المجلد إلى المستودع.
3. بمجرد رفع الملفات، ستلاحظ تلقائياً بدء سير العمل في تبويب **Actions** بفضل ملف `.github/workflows/build-apk.yml`.
4. بعد حوالي دقيقتين أو ثلاث، ستظهر علامة صح خضراء (Success).
5. اضغط على الـ Workflow المكتمل، وستجد في الأسفل في قسم **Artifacts** ملفاً جاهزاً للتحميل باسم:
   👉 **OfflineVoiceAssistant-Debug-APK**
6. قم بتحميله وفك ضغطه وستحصل على ملف `app-debug.apk` الجاهز للتثبيت على هاتفك فوراً!

---

## 📱 تفعيل التعرف الصوتي دون إنترنت على الهاتف:
1. افتح إعدادات الهاتف (Settings) -> Google.
2. إعدادات تطبيقات Google -> البحث والمساعد الصوتي وVoice -> الصوت (Voice).
3. التعرف على الكلام في وضع عدم الاتصال (Offline Speech Recognition).
4. انتقل لتبويب "الكل" (ALL) وحمل حزمة "العربية" (Arabic).
